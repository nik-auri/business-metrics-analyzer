# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения». Практическая работа № 1: настройка среды разработки и управление версиями.

## Бизнес-задача

Расчёт ключевых показателей эффективности (KPI) предприятия на основе ежемесячной выручки. Проект служит основой для дальнейшего анализа и визуализации показателей.

## Используемые технологии

- Python 3.10+
- pandas — обработка табличных данных
- matplotlib — библиотека для последующей визуализации
- Git и GitHub — управление версиями
- PyCharm — среда разработки

## Запуск в Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Если активация окружения недоступна, запускать можно напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

В PyCharm откройте папку проекта и выберите существующий интерпретатор `.venv\Scripts\python.exe`. Запустите `main.py` через Run.
