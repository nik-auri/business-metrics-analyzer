# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения». Практическая работа № 1: настройка среды разработки и управление версиями.

## Бизнес-задача

Расчёт ключевых показателей эффективности (KPI) предприятия на основе ежемесячной выручки. Проект служит основой для дальнейшего анализа и визуализации показателей.

## Используемые технологии

- Python 3.10+
- pandas — обработка табличных данных
- matplotlib — библиотека для последующей визуализации
- Git и GitHub — управление версиями
- PyCharm — среда разработки

## Запуск в Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Если активация окружения недоступна, запускать можно напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

В PyCharm откройте папку проекта и выберите существующий интерпретатор `.venv\Scripts\python.exe`. Запустите `main.py` через Run.

## Пример бизнес-задачи

Руководителю нужно оценить продажи за первый квартал. Демонстрационные данные: выручка 120 000, 150 000 и 135 000 руб.; затраты 90 000, 110 000 и 100 000 руб. Программа выводит таблицу, среднюю месячную выручку 135 000 руб. и рентабельность квартала 25,93%.

Формула в данной работе: `(выручка - затраты) / выручка * 100`. Это маржа прибыли по выручке. Общий показатель квартала рассчитывается по суммам, а не как среднее месячных процентов. При нулевой выручке функция возвращает 0,0% по условию задания.

## Планируемые метрики

- Общая и средняя месячная выручка.
- Суммарные затраты и прибыль.
- Маржа прибыли по выручке.
- В дальнейшем — динамика выручки и графики.
