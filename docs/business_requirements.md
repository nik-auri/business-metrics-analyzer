# Бизнес-требования

## Цель

Предоставить руководителю малого предприятия простой инструмент оценки выручки и прибыльности за квартал.

## Пользователи

Руководитель и бизнес-аналитик предприятия.

## Функциональные требования

1. Хранить демонстрационные значения месяца, выручки и затрат в коде.
2. Выводить данные в табличном виде с помощью pandas.
3. Вычислять среднюю месячную выручку.
4. Вычислять маржу прибыли за период: `(сумма выручки - сумма затрат) / сумма выручки * 100`.
5. При нулевой выручке возвращать 0,0% согласно учебному условию.

## Нефункциональные требования

- Python 3.10 или новее.
- Изолированное окружение и воспроизводимые зависимости в requirements.txt.
- Понятный вывод на русском языке.
- Исходные файлы и документация под управлением Git; окружение и секреты исключены через .gitignore.

## Критерии приёмки

- Запуск `python main.py` завершается без ошибок.
- Для выручки [120000, 150000, 135000] среднее равно 135000.
- Для общей выручки 405000 и затрат 300000 маржа составляет 25,93% после округления.
- `calculate_profitability(0, 100)` возвращает 0,0; `calculate_profitability(100, 120)` возвращает -20,0.

## Ограничения текущей версии

Файлы пользователя не импортируются, графики пока не строятся. Все суммы демонстрационные, в рублях. Проверка корректности произвольных входных данных относится к дальнейшему развитию.
